##QAsystem重构中

#1、硬盘暂存
分离各个步骤的运行，将中间结果全量保存在硬盘，减少重复计算，增加程序容错
！大量的硬盘写入/读取可能耗时较长，首次全流程的处理耗时增加，具体硬盘读写耗时待测试，问题应该不大

#2、pdf文件预处理技术调整
调用MinerU库，使用机器学习技术，使文字、图片的识别、截取更准确，输出内容更结构化
！耗时增加，使用纯CPU的pipeline模式单PDF处理在3~10分钟，使用GPU能增加识别准确率，减少识别耗时
!MinerU库的依赖限制，将python版本回退至3.11

#3、参数保存调整
一般参数，包括默认路径保存在paras.py中
敏感隐私数据，如api_key应该再单独保存，避免错误上传互联网（待进一步分离到api_keys.py）
